# Brand assets

Place the following files in this directory:

- `wayka.pdf` — the master brand & vision document.
- `logo/` — final logo files (SVG, PNG variants).
- `palette/` — any extended color references.

These files are referenced from later phases (catalog imagery, OG images,
favicon set, etc.). For Phase 1 they are not required.

When `wayka.pdf` is added, delete this placeholder file.
